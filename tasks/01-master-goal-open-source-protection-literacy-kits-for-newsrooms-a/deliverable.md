## Consolidated kit index (README draft)

```text
# Open Source-Protection Literacy Kits for Newsrooms and NGOs

MIT-licensed education kit for lawful source-protection literacy.
Complements sealed tip products (e.g. SafeDeposit-class tools) without rebuilding a drop server.
Proposer context: @SafeDepositOrg / https://safedepositbox.org/

## Not legal advice
Technical OPSEC only. No anonymity or immunity guarantee.
Prefer personal safety. Human edit before institutional adoption.

## Dual-use rails
No malware. No unauthorized access. No civilian surveillance tooling.
No private vendetta coaching. No private keys or tip ciphertext in the kit.

## Contents (map leaves -> files after accept)
1. Source OPSEC literacy pack (defensive)
2. Multi-channel key verification playbook
3. Secure-drop evaluation rubric for desks
4. Transparency templates (canary + desk charter + protect card)
5. Agent pack: training lesson from a one-line goal
6. Peer-review rubric + consolidator instructions

## How desks use this
1. Publish honest protect / do-not-protect + charter (templates).
2. Train session hygiene (OPSEC pack).
3. Train multi-channel key verify before high-risk encrypt.
4. Compare tip paths with the evaluation rubric (SecureDrop != independent sealed drops).
5. Optional: generate more lessons with the agent pack.
6. Review new material with the peer-review rubric before merge.

## Public receipts
See leaf table in master coordination document / receipts/CONTRIBUTIONS.md
```
